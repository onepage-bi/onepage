Напиши самодостаточный HTML-файл — аналитический отчёт.

ЖЁСТКИЕ ТРЕБОВАНИЯ
1. Никаких внешних запросов: весь CSS, JS и шрифты внутри файла.
   Если нужна библиотека — встрой её код в <script>, ссылки на CDN запрещены.
   (Отчёт, который читает файл ПРЯМО НА ПЛАТФОРМЕ, — другой случай: там
   доступен SheetJS с нашего сервера, см. промт «точный протокол».)
2. Файл должен работать офлайн при открытии двойным кликом.
3. Вес самого файла отчёта ≤ 1,5 МБ — выше платформа показывает в списке
   заглушку вместо живого превью. Данных больше — вынесем их отдельным
   файлом, отчёт будет их принимать.
4. Все цвета задавай CSS-переменными в :root и перерисовывай графики
   по событию window.addEventListener('op:theme', redraw).
