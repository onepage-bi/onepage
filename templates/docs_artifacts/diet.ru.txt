У меня самодостаточный HTML-отчёт, данные вшиты в разметку.
Разнеси его на две части, не переписывая рендеры.

1) HTML без данных: <script id="bootstrap-snapshot" type="application/json">{}</script>
   пустой; при старте отчёт шлёт parent.postMessage({type:"op_ready", slots:[0]}, "*")
   и слушает {type:"op_file", slot:0, data:ArrayBuffer}, из которого строит всё
   как раньше.

2) Файл данных для слота 0: если данных больше ~1 МБ — не JSON, а бинарный
   колоночный формат (типизированные массивы + словари строк) с маленьким
   JSON-заголовком схемы; декодируй в представления без полного JSON.parse.

Фильтрация должна материализовать только отфильтрованное подмножество,
а не копию всех данных. Таблицу рендери постранично, графики создавай
лениво при появлении в видимой области.
